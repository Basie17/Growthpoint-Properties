Growthpoint Properties Website

1. Project Overview
The Growthpoint Properties website was developed to provide visitors with information about the company and its property services. The website allows users to explore office, retail and commercial properties, learn about the company and submit enquiries.

2. Website Pages
The website consists of five main pages:
Home: Introduces Growthpoint Properties and highlights its services.
About Us: Provides information about the company, its mission, vision and values.
Properties: Displays office, retail and commercial property options.
Enquiry: Allows vivtors to submit property enquiries.
Contact: Provides contact information and a contact form.

3. Technologies Used
HTML - Website structure and content.
CSS - Website styling, colours, fonts and responsive layout.
JavaScript - Interactive features, search functionality and form validation.

4. Part 3 Improvements
The following improvements were made:
Added an image gallery lightbox.
Added a property search feature.
Added form validation and confirmation messages to the enquiry form and contact forrms.
Integrated FormSubmit to send enquiry and contact form submissions directly to the desgined email inbox.
Improved website SEO using page titles and meta descriptions.
Reviewed heading structures across all website pages.
Added descriprive alternative text to images.
Created a robots.txt file and an XML sitemap.
Maintained external CSS and JavaScript files.

5. Website Structure
The project contains HTML pages, a CSS folder, an Images folder, a JavaScript folder and supporting SEO and documentation files.

6. Conclusion
The improvements aim to make the Growthpoint Properties website more interactive, accessible, user friendly and easier for search engines to understand.
